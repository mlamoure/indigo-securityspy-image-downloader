# Runtime dependencies.
#
# Indigo (2023.2+) automatically pip-installs this file into Contents/Packages
# when the plugin is installed or updated on the server — so this copy must
# stay RUNTIME-ONLY. Never list dev/test tools here; they would be installed
# onto every end user's machine. Dev deps live in the repo-root requirements.txt.
#
# Unlike the stdlib-only plugins in this family (Roomie, Just Add Power),
# requests and Pillow are hard runtime deps here: image download, stitching,
# resizing, and GIF assembly are this plugin's core features.
# Note: Pillow 13+ requires Python >= 3.11 (Indigo 2023.2+ ships 3.11; Indigo 2026.1 runs 3.13).
# Pillow 13.0.0 is the first release with fixes for the Pillow 12.x OSV advisories.
requests~=2.34
pillow~=13.0
